# Security

This repository must not contain secrets, access tokens, credentials, private communications, financial data, contact or location data, production exports, or device backups.

If sensitive material is committed:

1. Stop further distribution.
2. Rotate or revoke the exposed credential when applicable.
3. Preserve enough evidence to understand the exposure without copying the sensitive value into issues or chat.
4. Remove the material using a reviewed history-rewrite plan when necessary.
5. Record the incident and corrective actions without reproducing the secret.

Security and privacy analysis in this repository is advisory governance. It does not make an agent a legal authority and does not create restrictions beyond controls actually enforced by the current runtime or tooling.
